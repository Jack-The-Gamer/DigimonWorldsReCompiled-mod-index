# Listed mods

One folder per mod, named `<YourName>@<mod id>`, holding `description.md`,
optionally `thumbnail.png`, and either

* `meta.json`, pointing at the mod's own repository — copy
  [`../examples/YourName@example-mod/`](../examples/YourName@example-mod) to start; or
* `mod/`, the mod itself, released from the index's repository (see
  [`Jack-The-Gamer@turbo`](Jack-The-Gamer@turbo) and
  [Hosting a mod in an index](../README.md#hosting-a-mod-in-an-index)).

See the [README](../README.md) for every field.
