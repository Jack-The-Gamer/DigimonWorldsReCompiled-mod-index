# Turbo Text

Hold the turbo button and Cross is tapped for you every few frames, so dialogue flies by. The game never sees the turbo button itself, so nothing changes unless you hold it. Works in Digimon World, Digimon World 2 and Digimon World 3.

**Options**

- **Turbo button**: R2 (default), L2, R1, L1 or Select
- **Button to tap**: Cross (default) or Circle
- **Frames per tap**: 4 by default, from 2 (fastest) to 30

While the mod is on, the game never receives the turbo button at all, so choose one you don't otherwise need.
