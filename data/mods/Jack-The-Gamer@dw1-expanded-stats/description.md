# DW1 Expanded Stats

Shows three numbers the game keeps track of but never shows you, on your Digimon's **status screen** (Menu → Digimon):

- **Tired**: a tiredness meter under Vir., with a sweat-drop icon. Its bar fills as your Digimon gets tired (0 to 100), the same way the virus bar does.
- **MISTAKES**: how many care mistakes your Digimon has made.
- **BATTLES**: how many battles your Digimon has won.

Care mistakes and battles are what the game checks for many digivolutions, so you can now see where you stand.

Everything matches the screen around it. The numbers and boxes are drawn exactly like AGE and WEIGHT, and "Tired" is written in the same lettering as Life and Disc. MISTAKES and BATTLES use the NAME / DIGI / AGE / WEIGHT lettering; the game doesn't have every letter they need, so the mod draws the missing ones in the same style.

To make room for the new row, Life, Happiness, Disc. and Vir. move up one row. They now line up with MP, Off, Def and SPEED, and Tired lines up with BRAINS.

**Notes**

- The game itself starts care mistakes and battles again from 0 when your Digimon digivolves.
- Numbers show up to 999.
- Only the status screen changes; the rest of the game plays exactly as before.

Made for Digimon World (USA, SLUS-01032) and checked there. Before it changes anything, the mod checks that the status screen's code is exactly what it expects. On any other version it does nothing.

Needs Re:Compiled 0.2.6 or newer.
