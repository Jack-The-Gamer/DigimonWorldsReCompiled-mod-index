# DW3 Disable Random Encounters

Switch random battles off whenever you like, and back on again.

- **R**: random encounters off. A red sign appears in the top right corner of the screen.
- **R** again: random encounters back on, and the sign goes away.

A message on screen also says "Random encounters off" or "Random encounters on" each time.

- Only random battles stop. Battles the story starts, and bosses, still happen.
- That includes the hidden battle spots some fields have, such as the one in the Wire Forest: with encounters off you walk straight over them.
- The game counts down to its next random battle with every step you take. While encounters are off the countdown simply waits, so switching them back on carries on from where it was: no battle the moment you switch back.
- Random encounters are on every time the game starts.
- R only does this while the game is running and not paused. If you have bound R to a controller button in **Settings → Controls**, it does both.

Made for Digimon World 2003 (SLES-03936) and checked there. It looks for the game's code rather than relying on fixed addresses, and that code is on the Digimon World 3 (USA) and (Japan) discs too, so they should work as well.
