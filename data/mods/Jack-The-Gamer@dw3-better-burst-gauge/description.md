# DW3 Better Burst Gauge

Your Digimon's burst gauges keep their progress when you load a save.

In the normal game the burst gauge under each partner's party slots is never written to the memory card: switch the game off, or load a save, and every gauge starts from empty again. With this mod, each save remembers the gauges it was made with, and loading that save puts them back, even after closing the program.

- Each save keeps its own gauges: load an older save and you get the gauges from when it was made.
- Works with every partner Digimon's gauge, and with saves on either memory card.
- Saves made before installing the mod (or without it) load exactly as before.
- Nothing about how the gauge fills or what happens when it is full changes.

The gauges are kept in this mod's own data in Re:Compiled (your memory card files are not changed), so they come back when you load your saves in Re:Compiled with the mod switched on.

Made for Digimon World 2003 (SLES-03936) and checked there, and on Digimon World 3 (Japan). It looks for the game's code rather than relying on fixed addresses, so Digimon World 3 (USA) should work too.

Needs Re:Compiled 0.2.6 or newer.
