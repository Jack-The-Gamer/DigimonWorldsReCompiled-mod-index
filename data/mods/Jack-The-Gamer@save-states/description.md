# Save States

Save the game exactly where you are, at any moment, and come back to it later.

- **1, 2, 3, 4, 5**: save to slot 1 to 5
- **Shift + 1 to 5**: load that slot

A message in the corner of the screen says what happened ("Saved state 2", "Loaded state 2", "Slot 4 is empty").

- Works in Digimon World, Digimon World 2 and Digimon World 3 / 2003, in every release.
- Each release has its own five slots, kept in Re:Compiled's data folder (`states/`), so they survive closing the game. A slot only loads in the release it was saved in, with the same BIOS.
- Memory cards are not part of a save state: loading one never takes your saves back, and saving to the memory card in the game works as usual.
- The number keys only do this while a game is running and not paused. If you have bound 1 to 5 to controller buttons in **Settings → Controls**, they do both.

Needs Re:Compiled 1.3 or later.
